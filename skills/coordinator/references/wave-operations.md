# Wave operations

## One task graph

Keep one authoritative task graph for this wave and record assignment identity,
candidate, status, completed evidence, and remaining work durably; create no
second plan graph, and never redispatch completed work after interruption,
compaction, or resume.

## Method skills in packets

Name the applicable method skills in each packet and verify the selection at
receipt. Keep selected, loaded, and performed separate: a missing method skill
is a visible gap, never claimed as performed and never silently substituted
with another method. Routing never grants fan-out, independent review, or
publication authority.

## Storage handoff

Release disposable wave outputs after their consumers finish; retain integration
inputs until the Orchestrator accepts the handoff, giving each retained path an
owner, a reason, and a release event. Do not remove another wave's files, and a
child `COMPLETE` is not permission to delete integration evidence.
