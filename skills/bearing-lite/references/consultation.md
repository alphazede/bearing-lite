# Specialist consultation return

Where the frozen profile preauthorizes specialist consultation, the Orchestrator preselects and dispatches the consultant. The assigned agent may request and receive bounded advice. The consultant does not choose itself.

The return is compact structured guidance addressed to the original agent: an addressee of `original_agent` and bounded guidance text. It carries no dispatch, route, model, harness, write set, or ownership field.

Ownership stays with the original agent and the Orchestrator. Consultation does not transfer orchestration ownership, model route, or review identity, and it is not a new implementation attempt or review round.
