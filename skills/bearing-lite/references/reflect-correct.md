# Reflect and correct

At closeout, list corrections the owner gave, facts an agent had to
rediscover, and checks skipped on the real artifact. Keep a lesson only if it
will still hold in six months, changes what a future agent does, and is not
already stated in the target file. Drop versions, hashes and counts.

Fix each lesson at the highest level that works. A test change or a
documentation edit applies directly through normal review as a strict,
concise, precise edit. A new lint, hook, gate or type-level guard goes to the
owner as a proposal. Each new test must fail on the real past mistake before
it lands. Never edit a frozen profile or authority record.

This adds no agent, review or stop. It is a closeout step of the controller.
An edit stays inside the recorded write set. A needed file outside that set
returns to the Orchestrator.
