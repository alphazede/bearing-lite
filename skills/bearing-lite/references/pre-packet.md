# Pre-packet check

Before composing a packet, the Orchestrator runs the handoff compiler's field
check: one objective, observable acceptance, write set, existing commands and
named evidence. A missing or empty field is a compilation gap, not a packet.
The Orchestrator uses that compiler instead of writing the packet by hand.

It then runs the advisory decision-model check: is the objective one
observable outcome, and is each acceptance item observable by something other
than the author? Name the rawest source the agent should read instead of a
summary. Settle by experiment any choice an experiment can settle. Send the
uncertain band to the owner. Reuse settled planning; never re-interview.

Do not trust this advisory check until its objective and acceptance judgments
have been measured on real packets. The Prompt skill stays the composer of
the bounded handoff for the assignment the Orchestrator already selected.
